# Recruiter showcase

## Title
Enterprise AI Knowledge & Research Assistant

## LinkedIn description
Built a production-oriented GenAI knowledge assistant using Python, FastAPI, LangChain and React. Implemented multi-format enterprise document/web ingestion, chunking, Hugging Face embeddings, PostgreSQL/pgvector, hybrid BM25 + vector retrieval, cross-encoder reranking, local LLM inference, citation-grounded RAG, JWT/RBAC, agent tool routing, and an evaluation dashboard for retrieval quality, groundedness, citation accuracy, latency and token usage.
